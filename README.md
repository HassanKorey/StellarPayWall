# StellarPayWall

A High-Throughput HTTP 402 Stellar Micropayment API Gateway & Middleware for API Monetization, Agentic Payments, and Soroban Asset Verification.

## Architecture
See documentation for architecture diagrams and local setup.

## Setup
`docker-compose up -d`
`pip install -r requirements.txt`
`uvicorn stellarpaywall.main:app --reload`
